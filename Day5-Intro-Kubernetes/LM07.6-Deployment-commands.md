# Kubernetes Continuation Lab Manual (Intermediate)

## ✅ 1. Create a Deployment Instead of Pod

### Why?

Pods created directly are not self-healing.

Create deployment:

```bash
kubectl create deployment nginx-deploy --image=nginx
```

Verify:

```bash
kubectl get deployments
kubectl get pods
```

---

# ✅ 2. Scale the Deployment

Scale to 3 replicas:

```bash
kubectl scale deployment nginx-deploy --replicas=3
```

Verify:

```bash
kubectl get pods
```

Observe multiple pods running.

# ✅ 3. Expose Deployment as NodePort

# ✅ 7. Execute Commands Inside Container

Open shell:

```bash
kubectl exec -it <POD-NAME> -- /bin/bash
```

OR:

```bash
kubectl exec -it <POD-NAME> -- sh
```

Check nginx files:

```bash

ls
```

```bash

```

# ✅ 11. Create Deployment Using YAML

Sample YAML:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: webapp
spec:
  replicas: 2
  selector:
    matchLabels:
      app: webapp
  template:
    metadata:
      labels:
        app: webapp
    spec:
      containers:
      - name: nginx
        image: nginx
        ports:
        - containerPort: 80
```

Apply YAML:

```bash
kubectl apply -f webapp.yaml
```

# ✅ 12. Update Image Version

Check current image:

```bash
kubectl describe deployment nginx-deploy
```

Update image:

```bash
kubectl set image deployment/nginx-deploy nginx=nginx:1.25
```

Verify rollout:

```bash
kubectl rollout status deployment/nginx-deploy
```

View rollout history:
